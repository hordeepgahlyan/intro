# hordeep // terminal

> a retro terminal portfolio. because why build a normal one?

**Live:** [intro-mocha.vercel.app](https://intro-mocha.vercel.app)

---

## what is this

a fully interactive terminal-style portfolio built from scratch.
boots up, splashes an ascii banner, then drops you into a fake shell
where you can actually run commands and explore.

yes, i built a terminal to avoid building a normal portfolio.
no regrets.

---

## stack

- **next.js 16** · **typescript** · **tailwind css**
- web audio api (for the keyboard click sounds)
- html5 canvas (you'll know when you find it)
- deployed on **vercel**

---

## running locally

```bash
git clone https://github.com/hordeepgahlyan/intro
cd intro
npm install
npm run dev
```

open [http://localhost:3000](http://localhost:3000)

## commands

type `help` in the terminal to see available commands.

some highlights:

| command    | what it does      |
| ---------- | ----------------- |
| `about`    | who I am          |
| `projects` | things i've built |
| `skills`   | tech i know       |
| `contact`  | reach me          |
| `ls`       | list files        |
| `neofetch` | obligatory        |
| `hire-me`  | run it. trust me. |
| `lore`     | the origin story  |
| `joke`     | random dev joke   |

> not all commands are listed. curiosity is rewarded here.
